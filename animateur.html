ELECARM Crisis2
Réservé à l'enseignant. Pilote l'ouverture de l'exercice, gère les groupes et suit leurs suppositions.

Accès animateur

Lien unique à donner aux élèves

Sur ce lien, chaque élève choisit son TD, puis son groupe, tape son nom et prénom, attend le lancement, puis entre dans l'exercice. Les élèves ne créent rien : ils rejoignent les groupes que vous avez créés ci-dessous. Le site n'est accessible que lorsque vous l'ouvrez.

État de l'exercice

--
Ouvrir l'exercice : le jeu se lance tout de suite ; les élèves sur /salle qui ont rejoint leur groupe entrent directement, les autres entrent dès qu'ils rejoignent le leur. Compte à rebours : décompte synchronisé, l'exercice s'ouvre à zéro. Salle d'attente : les élèves rejoignent leur groupe avant de commencer. Fermer : bloque l'exercice sur tous les postes (sans perte de progression) ; « Ouvrir l'exercice » le rouvre. Veille : site fermé. L'exercice n'a pas de limite de temps : il reste ouvert jusqu'à ce que vous le fermiez. Un élève doit avoir rejoint un groupe pour entrer dans le jeu.

Groupes

« Créer les groupes » ajoute seulement les groupes manquants (TD1 à TD4, Groupe 1 à 4 par défaut) : les groupes existants et leurs élèves ne sont pas touchés. Sur chaque groupe : + place / - place, ⇄ pour déplacer un élève vers un autre groupe (son poste suit tout seul), × pour le retirer (il rejoint à nouveau depuis /salle).

Relance

Envoie une notification « alerte » sur l'écran de tous les groupes (elle apparaît en moins de 20 secondes). Utile pour relancer un groupe qui s'essouffle ou mettre la pression.
